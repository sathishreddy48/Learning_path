Data Lake Storage Gen2 and Parquet

ADLS Gen2 is Blob Storage with a hierarchical namespace (real directories, POSIX ACLs) — the landing zone for analytics. Store columnar Parquet (or Delta) partitioned by date; every engine (Synapse, Databricks, Fabric, DuckDB, pandas) reads it. Layout convention: bronze/ raw, silver/ cleaned, gold/ aggregated.

// Write events to the lake as Parquet, one file per hour (Parquet.Net + Azure.Storage.Files.DataLake)
var lake = new DataLakeServiceClient(new Uri("https://dlsshop.dfs.core.windows.net"), new DefaultAzureCredential());
var fs = lake.GetFileSystemClient("bronze");
var path = $"orders/year={now:yyyy}/month={now:MM}/day={now:dd}/orders-{now:HH}.parquet";

await using var ms = new MemoryStream();
await ParquetSerializer.SerializeAsync(orders, ms);          // orders: IEnumerable<OrderRow> (plain POCO)
ms.Position = 0;
var file = fs.GetFileClient(path);
await file.UploadAsync(ms, overwrite: true);

// ACLs are per directory/file (in addition to RBAC) — grant the analytics SP read on silver/
var dir = fs.GetDirectoryClient("silver");
await dir.SetAccessControlRecursiveAsync(new[] { new PathAccessControlItem(AccessControlType.User, RolePermissions.Read | RolePermissions.Execute, entityId: analyticsSpObjectId) });
# pandas / pyarrow straight against the lake with identity auth
import pandas as pd
from azure.identity import DefaultAzureCredential

storage_options = {"account_name": "dlsshop", "credential": DefaultAzureCredential()}   # via adlfs
df = pd.read_parquet("abfs://bronze/orders/year=2026/month=09/", storage_options=storage_options)
daily = df.groupby(df.created.dt.date).agg(orders=("id", "count"), revenue=("total", "sum")).reset_index()
daily.to_parquet("abfs://gold/daily_sales/2026-09.parquet", storage_options=storage_options, index=False)

# DuckDB for ad-hoc analysis without a cluster
import duckdb
duckdb.sql("SELECT country, sum(total) FROM read_parquet('bronze/orders/**/*.parquet', hive_partitioning=true) GROUP BY 1 ORDER BY 2 DESC")
Interview angle

Why columnar formats for analytics; partition pruning; hierarchical namespace vs flat blobs (rename cost, ACLs); medallion layout; small-files problem and compaction; lifecycle policies to cool/archive old partitions.

Data Factory, Synapse and Microsoft Fabric

Data Factory orchestrates copy and transform activities (100+ connectors, mapping data flows, triggers). Synapse bundled pipelines with serverless SQL and Spark pools. Microsoft Fabric is the current SaaS umbrella (OneLake, Lakehouse, Warehouse, pipelines, Power BI) and where new investment goes. Application teams mostly need to: land data reliably, expose a change feed, and avoid hammering the OLTP database.

Azure AI Search: indexes, indexers and vector search

Azure AI Search is a managed search engine: define an index (fields, analyzers, vector profiles), push documents from code or pull them with an indexer (Blob, SQL, Cosmos) plus a skillset (OCR, chunking, embedding). Query with full-text (BM25), vectors (HNSW) or hybrid + semantic ranker. It is the retrieval layer of most Azure RAG systems.

// Index definition with a vector field
var indexClient = new SearchIndexClient(new Uri("https://srch-shop.search.windows.net"), new DefaultAzureCredential());
var index = new SearchIndex("products")
{
    Fields =
    {
        new SimpleField("id", SearchFieldDataType.String) { IsKey = true },
        new SearchableField("name") { AnalyzerName = LexicalAnalyzerName.EnLucene },
        new SearchableField("description"),
        new SimpleField("category", SearchFieldDataType.String) { IsFilterable = true, IsFacetable = true },
        new SimpleField("price", SearchFieldDataType.Double) { IsFilterable = true, IsSortable = true },
        new VectorSearchField("embedding", vectorSearchDimensions: 1536, vectorSearchProfileName: "hnsw")
    },
    VectorSearch = new() { Profiles = { new VectorSearchProfile("hnsw", "hnsw-cfg") }, Algorithms = { new HnswAlgorithmConfiguration("hnsw-cfg") } },
    SemanticSearch = new() { Configurations = { new SemanticConfiguration("default", new() { TitleField = new("name"), ContentFields = { new("description") } }) } }
};
await indexClient.CreateOrUpdateIndexAsync(index);

Azure OpenAI: chat, embeddings and structured output

Deploy a model (e.g. gpt-4.1, o4-mini, text-embedding-3-large) in an Azure OpenAI / AI Foundry resource and call it with the OpenAI-compatible SDK using Entra auth. Production concerns: TPM quotas and 429s, prompt caching, content filters, structured output for anything you parse, and logging prompts/completions with correlation IDs (minus PII).

The RAG pattern end to end

Retrieval-Augmented Generation: chunk and embed your documents into AI Search, at question time retrieve the top chunks (hybrid), build a prompt with citations, call the model, and return the answer with the sources. The quality levers are chunking, hybrid + reranking, prompt discipline (answer only from context) and evaluation — not the model. Keep security trimming in the search filter so users only retrieve what they may see.

public class RagService(SearchClient search, EmbeddingClient embed, ChatClient chat)
{
    public async Task<Answer> AskAsync(string question, string userId, CancellationToken ct)
    {
        // 1) retrieve — hybrid + semantic, security-trimmed
        var qv = (await embed.GenerateEmbeddingAsync(question, cancellationToken: ct)).Value.ToFloats();
        var hits = await search.SearchAsync<Chunk>(question, new SearchOptions
        {
            VectorSearch = new() { Queries = { new VectorizedQuery(qv) { KNearestNeighborsCount = 30, Fields = { "embedding" } } } },
            Filter = $"allowedUsers/any(u: u eq '{userId}') or isPublic eq true",
            QueryType = SearchQueryType.Semantic, SemanticSearch = new() { SemanticConfigurationName = "default" }, Size = 6
        }, ct);
        var chunks = new List<Chunk>();
        await foreach (var h in hits.Value.GetResultsAsync()) chunks.Add(h.Document);

        // 2) prompt with numbered sources
        var context = string.Join("\n\n", chunks.Select((c, i) => $"[{i + 1}] ({c.Title}) {c.Text}"));
        var messages = new ChatMessage[]
        {
            new SystemChatMessage("Answer using ONLY the sources. Cite as [n]. If the sources do not contain the answer, say you don't know."),
            new UserChatMessage($"Sources:\n{context}\n\nQuestion: {question}")
        };

        // 3) generate
        var result = await chat.CompleteChatAsync(messages, new ChatCompletionOptions { Temperature = 0, MaxOutputTokenCount = 600 }, ct);
        return new Answer(result.Value.Content[0].Text, chunks.Select(c => new Source(c.Title, c.Url)).ToList());
    }
}
// Evaluate: a golden set of (question, expected facts) → groundedness / relevance scores per release. Log retrieval hits with the answer.
def ask(question: str, user_id: str) -> dict:
    qv = client.embeddings.create(model="text-embedding-3-large", input=question).data[0].embedding
    hits = list(search.search(
        search_text=question,
        vector_queries=[VectorizedQuery(vector=qv, k_nearest_neighbors=30, fields="embedding")],
        filter=f"allowedUsers/any(u: u eq '{user_id}') or isPublic eq true",
        query_type="semantic", semantic_configuration_name="default", top=6))
    context = "\n\n".join(f"[{i+1}] ({h['title']}) {h['text']}" for i, h in enumerate(hits))
    resp = client.chat.completions.create(model="gpt-4.1", temperature=0, max_tokens=600, messages=[
        {"role": "system", "content": "Answer using ONLY the sources. Cite as [n]. If the sources do not contain the answer, say you don't know."},
        {"role": "user", "content": f"Sources:\n{context}\n\nQuestion: {question}"}])
    return {"answer": resp.choices[0].message.content, "sources": [{"title": h["title"], "url": h["url"]} for h in hits]}

# Ingestion: split with overlap (e.g. 500 tokens / 50 overlap), embed in batches of 16–100, upload with a stable chunk id = f"{doc_id}-{n}"
# so re-indexing a changed document overwrites its chunks and a deleted document's chunks can be removed.
Interview angle

Why RAG over fine-tuning for private, changing data; chunk size and overlap; hybrid retrieval and reranking; hallucination controls (grounding instruction, citations, refusal); security trimming; evaluation (groundedness, relevance, golden set) and monitoring in production; caching and cost.

Azure AI services: Document Intelligence, Language, Vision

Prebuilt models extract structured data from invoices, receipts, IDs and forms (Document Intelligence); Language does PII detection, sentiment, summarisation and entity extraction; Vision does OCR and image analysis; Speech transcribes. They are REST/SDK calls with the same identity story as everything else and frequently feed the ingestion side of a RAG or automation pipeline.
