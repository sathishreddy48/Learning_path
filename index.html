How to use this site
  • Start with Core Concepts and go in order — later pages assume the earlier ones.
  • Every code sample has a C# | Python tab bar. Switch tabs to see the same concept in the other language; Copy grabs whatever tab is showing.
  • Each section ends with a Practice box. Do the exercise in both languages before moving on.
  • Interview angle boxes call out what a senior-level interviewer will probe on that topic.
  • Visited state lives in your browser only. Use Reset visited topics to start a fresh pass.

Suggested order

The sidebar is already in study order. Roughly: language (1–2) → building services (3–7) → algorithms & runtime (8–9) → architecture (10–11) → platform & delivery (12–13). If you are short on time, the highest-yield pages for a senior C# interview are Core Concepts, Threading, Web API, Security and Performance.
