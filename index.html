C# Learning Path

A self-paced study site for C# / .NET preparation — from the language core through threading, Web API, security, data access and patterns, then the Azure platform and the DevOps practice that gets it to production. Every topic page pairs C# with the equivalent Python (or the YAML / CLI the topic really uses) so you can practise the same idea in both. The sidebar has three menus — C# & .NET, Azure and DevOps; pages you have opened turn ✓ visited.

How to use this site
  • Start with Core Concepts and go in order within a menu — later pages assume the earlier ones. The Azure and DevOps menus can be studied in parallel once you are past Web API.
  • Every code sample has a C# | Python tab bar. Switch tabs to see the same concept in the other language; Copy grabs whatever tab is showing.
  • Each section ends with a Practice box. Do the exercise in both languages before moving on.
  • Interview angle boxes call out what a senior-level interviewer will probe on that topic.
  • Visited state lives in your browser only. Use Reset visited topics to start a fresh pass.

Topics

Suggested order

Each sidebar menu is already in study order. Roughly: language (1–2) → building services (3–7) → algorithms & runtime (8–9) → architecture (10–11) → Azure platform (12–17) → DevOps & operations (18–23). If you are short on time, the highest-yield pages for a senior C# interview are Core Concepts, Threading, Web API, Security and Performance; for a cloud-leaning role add Azure Services, Entra ID, Azure Architecture, Azure DevOps and Observability.
